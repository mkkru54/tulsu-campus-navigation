# Навигация по корпусу №9 ТулГУ — векторные планы

HTML/CSS/JavaScript без внешних зависимостей. Этажи 1–7 нарисованы программно: комнаты, стены, дверные проёмы, коридоры, служебные зоны и обозначения лестниц. На сайте нет скриншотов, обрезанных подложек или изображений 2ГИС. Расположение восстановлено вручную по семи скриншотам пользователя от 03.10.2026. Главный корпус «Гл-» исключён.

## Запуск

Откройте `index.html` двойным нажатием после распаковки архива. Либо выполните из папки проекта:

```sh
python3 -m http.server 8080 --bind 127.0.0.1
```

Откройте http://127.0.0.1:8080. Укажите номер (113 или 9-113) либо служебную точку. Комнаты можно выбирать нажатием по всей площади прямоугольника; они также доступны с клавиатуры. Масштаб и переключатель этажей расположены над планом.

## Данные и архитектура

- `data/building.json`: 141 читаемый номер кабинета, служебные точки, геометрия помещений и восстановленный граф. `plans[floor].shapes` содержит прямоугольники с координатами, размерами, типом и подписью; они редактируются независимо. Неизвестные номера перечислены в `pendingRooms` и не выдумываются.
- `data/building.js`: те же данные для запуска через `file://`.
- `plan.js`: рисует SVG-планы из векторных элементов. Коридоры, стены, подписи, ступени лестниц и дверные проёмы создаются программно. Нет элементов SVG image или растровых фонов.
- `app.js`: выбор точек, переключение этажей, масштаб, отображение маршрута и текстовые шаги.
- `routing.js`: независимая Дейкстра, O(V² + E). Двусторонние рёбра с неотрицательными весами; `closed: true` закрывает проход.
- `index.html`, `style.css`: интерфейс.
- `tests/routing.test.cjs`: проверки поиска пути и структуры графа.
- `previews/floor-N.svg`: отдельные векторные планы для просмотра и проверки. Они экспортированы тем же `plan.js`, который использует сайт.

Коридорные узлы отделены от дверей и центров комнат. Маршрут проходит через отдельные точки дверных проёмов; все внутриэтажные отрезки графа горизонтальные или вертикальные. Межэтажные рёбра соединяют лестничные площадки. Актовый зал доступен отдельной точкой на 4 этаже; уровень зала на 3 этаже тоже нанесён. Служебные точки включают гардероб, банкоматы, бюро пропусков, столовую, музей и санузлы.

## Точность

Это ручная векторная реконструкция по [планам 2ГИС](https://2gis.ru/tula?floor=1&m=37.586313%2C54.166954%2F18.94), а не архитектурный обмер. Сохранены взаимное расположение читаемых комнат, западное возвратное крыло, центральное крыло и основные лестничные зоны. Стены выровнены, размеры комнат и проёмы приблизительны. Номера с нечитаемыми подписями не включены в маршруты; подробные границы таких помещений требуют уточнения.

Точное место каждой двери, физическая непрерывность лестниц, доступность проходов и работа лифтов не подтверждены. Межэтажные соединения отмечены `vertical-connection-needs-survey`; двери — `door-needs-survey`. Лестница центрального крыла на 4–5 этажах восстановлена по совпадающим зонам; её соединение также предположительное. Маршруты через лифты не строятся.

Веса — расстояния в координатах плана плюс условный штраф 190 за этаж; это не метры и не минуты. Новый план позволяет точнее привязать маршрут к дверям и коридорам, но сам по себе не подтверждает точность реального маршрута.

## Дополнение

Правьте прямоугольники в `plans[floor].shapes`, координаты узлов `x/y`, поля `rect` и `door` соответствующей комнаты. Узел `door-ID` должен совпадать с её дверью. Рёбра задают фактическую возможность прохода; добавляйте вершины в поворотах, исключайте запертые связи. После обследования исправьте статусы и измерьте расстояния.

Синхронизация данных после изменения JSON:

```sh
python3 -c "import json,pathlib; p=pathlib.Path('data'); d=json.loads((p/'building.json').read_text()); (p/'building.js').write_text('window.BUILDING = '+json.dumps(d,ensure_ascii=False,indent=2)+';\n')"
```

## Проверка

```sh
node tests/routing.test.cjs
```

Проверяются обход дорогого ребра, обратный маршрут, совпадающие и неизвестные точки, закрытые связи, некорректные веса, уникальность ID, достижимость всех узлов, маршруты к служебным точкам, семь планов, положительные размеры помещений и отсутствие диагональных внутриэтажных рёбер. Векторные планы экспортированы и визуально проверены отдельно. Просмотр живого сайта в браузере ранее блокировала проверка политики доступа, поэтому браузерная проверка этой версии не подтверждена.
